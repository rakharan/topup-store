Syarat & Ketentuan

1. Cara Order

  1. Pilih game yang ingin di-top-up (Free Fire, Mobile Legends, PUBG Mobile, atau game HoYo yang tersedia)
  2. Pilih paket item/currency yang diinginkan
  3. Masukkan User ID (UID) akun game dengan benar
  4. Masukkan nomor WhatsApp aktif untuk konfirmasi
  5. Lakukan pembayaran melalui Midtrans Checkout sesuai metode yang tersedia
  6. Top-up akan diproses otomatis setelah pembayaran dikonfirmasi

2. Waktu Proses

Top-up akan diproses maksimal 10 menit setelah pembayaran dikonfirmasi oleh sistem. Jika dalam 10 menit top-up belum masuk, silakan hubungi admin melalui WhatsApp.

3. Format User ID (UID)

Free Fire: Masukkan angka UID saja (contoh: 123456789)

Mobile Legends: Masukkan Game UID dan Server ID pada kolom terpisah (contoh UID 12345678, Server 1234)

PUBG Mobile: Masukkan angka UID saja (contoh: 5123456789)

HoYo games: Masukkan UID dan Server pada kolom terpisah. Sistem akan mengirim format UID|Server ke supplier.

4. Tanggung Jawab Pengguna

  • Pastikan UID dan Server ID yang dimasukkan sudah benar sebelum melakukan pembayaran
  • Top-up yang dikirim ke UID atau Server ID yang salah karena kesalahan pengguna tidak dapat di-refund
  • Pastikan nomor WhatsApp yang dimasukkan aktif untuk menerima konfirmasi
  • Link pembayaran hanya berlaku untuk order yang sedang aktif

5. Pembayaran

  • Pembayaran diproses oleh Midtrans melalui metode yang tersedia, seperti GoPay, QRIS, Virtual Account, atau metode lain yang aktif pada halaman checkout
  • Ketersediaan metode pembayaran dapat berbeda berdasarkan perangkat, bank, e-wallet, dan status aktivasi kanal pembayaran
  • Beberapa bank atau aplikasi pembayaran dapat menerapkan minimum transaksi sendiri, terutama untuk pembayaran Virtual Account dari bank lain
  • Halaman pembayaran dapat terbuka melalui pop-up, halaman Midtrans, atau aplikasi pembayaran terkait
  • Order yang tidak dibayar dalam 30 menit akan otomatis kadaluarsa
  • Semua transaksi menggunakan mata uang Rupiah (IDR)
